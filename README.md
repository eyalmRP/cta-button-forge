# CTA Button Forge

Design call-to-action buttons and export them as PNG or SVG, one at a time or in batches.

**Open the app:** https://eyalmrp.github.io/cta-button-forge/

- No account needed. Everything runs in your browser.
- **Match a reference image:** load or paste a picture of a button and press **Auto-match design**. If it misses something, use the **Help the mimic** hints (font, letter case, icon, icon style, shape).
- Saved designs in **My designs** stay in your own browser.

The whole app is the single file `index.html`. To update it, replace that file; everyone gets the new version on their next visit.
